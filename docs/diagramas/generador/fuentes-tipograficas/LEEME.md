# Atkinson Hyperlegible Next

Copia de las cuatro caras que usa la aplicación (400, 500, 600, 700), tomadas
del paquete `@expo-google-fonts/atkinson-hyperlegible-next` que ya usa
`mobile/`.

Están aquí, y no se leen de `node_modules/`, para que el generador de
diagramas funcione sin haber instalado antes las dependencias de la app.

La diseñó el Braille Institute of America con el objetivo explícito de
aumentar la legibilidad para personas con baja visión. Se distribuye bajo la
SIL Open Font License 1.1, que permite usarla, incrustarla y redistribuirla.
